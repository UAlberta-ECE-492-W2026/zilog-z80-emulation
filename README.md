FPGA emulation of the Zilog Z80

## Running Simulations

To verify the design, simulations are used. 
The simulation will execute the designed hardware models inside a runtime.
During the simulation, a set of input vectors are passed into the model and the resulting output signal is compared with some expected value.

To run a simulation, the dependencies listed [here](#simulations) must be present in the environment.

From there, run make from the root directory of the project with a valid target. A list of target is available in the [simulation make targets header](#simulation-make-targets).

## Using Vivado

To actually program the Zybo FPGA you will need to use [Vivado](https://www.xilinx.com/support/download.html). We are using version 2025.2, specifically the free (non enterprise) version. When installing ensure that you add support for the zync 7000 series boards. 

Once Vivado is installed create a new project. Make sure to use a reasonable name and location. Click 'RTL Project' and make sure 'Do not specifiy sources at this time' is selected. To select the default part click 'Refresh', then once the catalog has been loaded click 'Boards' and search for "Zybo Z7-10". Click the download icon in the 'Status' column and wait for the download to complete. Make sure the part is selected and press 'Next' then 'Finish'. If you are using a different Xilinx FPGA then here is where you select the correct one. You will very likely need to update ./constraints/constraintsXDC.xdc unless the board is very similar to the Z7-10. 

Next we have to add all the files. This section assumes you have this git repository cloned somewhere convenient on the same machine that Vivado is installed on. In the 'Sources' panel right click 'Constraints' and click 'Add Sources'. Make sure 'Add or create constraints' is selected and hit next. Click add files and add the constraintXDC.xdc file from the src/constraints folder of this repo. Make sure 'Copy constraints files into project' is unchecked and hit finish. Open the add sources dialog again, but this time select 'Add or create design sources'. Add all the files inside src/enum and src/hdl. Open the 'Design Sources' drop down and make sure 'z80_top' is bold and has a icon with three squares next to it.

The last step of configuration is to  click 'Tools/Settings' in the menu at the top of the screen. Click the '...' next to 'Verilog Options' and add search paths to both the src/enum and src/hdl folders. Hit ok and apply.

Make sure the path in ./src/hdl/program_ram.sv is updated to the correct path of the .vivado file that you intend to use. For instructions on how to compile a program to a .vivado file see the README in our [software repo](https://github.com/UAlberta-ECE-492-W2026/zilog-z80-emulation-software).

Now a bitstream can be generated by clicking 'Generate Bitstream'. It is recommended to save this bitstream file somewhere for later use, so you don't need to regenerate the bitstream every time you want to run a program. A few sample bitstreams are included in ./sample_bitstreams. Note that these require the exact same FPGA development board (a Zybo Z7-10) to work.

## Hardware Setup

A VGA to PMOD adapter is plugged into PMOD ports JC and JD. A PMOD seven segment display is plugged into PMOD ports JA and JE. This requires some sort of cable. A suitable one is (or was) included in the UAlberta lab kit. Since the pins are a standard pitch it shouldn't be too difficult to source a cable for this purpose. Alternatively the seven segment display can be omitted, though this does make 'typing' more difficult. 

## Simulation Make Targets

- `make run_alu_8_tb` will execute the main function 8-bit ALU test bench
- `make run_alu_16_tb` will execute the main function 16-bit ALU test bench
- `make run_alu_8_status_tb` will execute the status signal test bench for the 8-bit ALU
- `make -f Makefile_<testbench name> run_sim` will run the corresponding testbench. Many of these are broken due to later changes to the interfaces of the tested module. All of the z80_top makefiles should run ok.

## Dependencies

### Simulations

For simulation purposes, the required programs are `make`, `verilator`, and `gcc`. Additionally, to view the resulting simulation waveform, a waveform viewer is required. The recommended open source waveform viewer is [GTKWave](https://github.com/gtkwave/gtkwave).

z88dk is complicated to install. See [the z88dk installation page](https://github.com/z88dk/z88dk/wiki/installation) for details. Note that the exact version of z88dk used in included as a submodule in our software repo, so if you want to build the exact version we used you can (though breaking changes are unlikely). Directions to do this are [in the software repo README](https://github.com/UAlberta-ECE-492-W2026/zilog-z80-emulation-software).

#### MacOS

The following command facilitates installation of the dependencies.

``` sh
brew install make verilator
```

Additionally, to view the output waveform, install GTKWave.

##### Resources

- [install GTKWave](https://gtkwave.github.io/gtkwave/install/mac.html "go to link")
  - Provides instructions on how to either install GTKWave using Homebrew Taps, or building from source. 
  Building from source here is relatively painless.

#### Arch linux

``` sh
pacman -S make verilator gcc
pacman -S gtkwave
```

#### Ubuntu/WSL 2.0 on Windows

``` sh
sudo apt install gtkwave
sudo apt install verilator
```
